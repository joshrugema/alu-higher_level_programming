# Python - Classes and Objects

First steps with object-oriented programming: classes, private attributes, properties (getters and setters) and methods, built up one step at a time on a `Square` class.

| File | What it does |
|------|--------------|
| 0-square.py | Defines an empty class Square |
| 1-square.py | Square with a private size attribute |
| 2-square.py | Checks that size is an integer and is >= 0 |
| 3-square.py | Adds a public area() method |
| 4-square.py | Adds a size property (getter and setter) with validation |
| 5-square.py | Adds my_print() to print the square with # |
| 6-square.py | Adds a position property so the square is printed with an offset |
