# Python - Exceptions

Practice with try / except / finally and raising exceptions.

| File | What it does |
|------|--------------|
| 0-safe_print_list.py | Prints up to x elements of a list, stops safely at the end |
| 1-safe_print_integer.py | Prints a value if it is an integer, returns True/False |
| 2-safe_print_list_integers.py | Prints only the integers among the first x elements |
| 3-safe_print_division.py | Divides two integers, prints the result in finally |
| 4-list_division.py | Divides two lists element by element, handling errors |
| 5-raise_exception.py | Raises a TypeError |
| 6-raise_exception_msg.py | Raises a NameError with a message |
