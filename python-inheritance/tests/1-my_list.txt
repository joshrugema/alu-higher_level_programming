How to use 1-my_list.py
=======================

MyList is a list (it inherits list) with one more method: print_sorted().

    >>> MyList = __import__('1-my_list').MyList

A MyList is still a list:

    >>> my_list = MyList()
    >>> isinstance(my_list, list)
    True
    >>> issubclass(MyList, list)
    True

An empty list prints an empty list:

    >>> my_list.print_sorted()
    []

print_sorted() prints the items in ascending order:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list does not change:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers and repeated numbers:

    >>> my_list = MyList([3, -1, 0, -7, 3])
    >>> my_list.print_sorted()
    [-7, -1, 0, 3, 3]

A list that is already sorted, and a list with one item:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]
    >>> MyList([89]).print_sorted()
    [89]

print_sorted() takes no argument:

    >>> my_list.print_sorted(1)  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError: takes 1 positional argument but 2 were given
