How to use 7-base_geometry.py
=============================

BaseGeometry has two methods: area() and integer_validator().

    >>> BaseGeometry = __import__('7-base_geometry').BaseGeometry
    >>> bg = BaseGeometry()

area() is not written yet in the base class:

    >>> bg.area()
    Traceback (most recent call last):
    Exception: area() is not implemented

integer_validator() says nothing when value is a positive integer:

    >>> bg.integer_validator("my_int", 12)
    >>> bg.integer_validator("width", 89)
    >>> bg.integer_validator("one", 1)

A value that is not an integer raises a TypeError:

    >>> bg.integer_validator("name", "John")
    Traceback (most recent call last):
    TypeError: name must be an integer

    >>> bg.integer_validator("pi", 3.14)
    Traceback (most recent call last):
    TypeError: pi must be an integer

    >>> bg.integer_validator("flag", True)
    Traceback (most recent call last):
    TypeError: flag must be an integer

    >>> bg.integer_validator("nothing", None)
    Traceback (most recent call last):
    TypeError: nothing must be an integer

    >>> bg.integer_validator("list", [3])
    Traceback (most recent call last):
    TypeError: list must be an integer

    >>> bg.integer_validator("tuple", (4,))
    Traceback (most recent call last):
    TypeError: tuple must be an integer

    >>> bg.integer_validator("dict", {3, 4})
    Traceback (most recent call last):
    TypeError: dict must be an integer

A value of 0 or less raises a ValueError:

    >>> bg.integer_validator("age", 0)
    Traceback (most recent call last):
    ValueError: age must be greater than 0

    >>> bg.integer_validator("distance", -4)
    Traceback (most recent call last):
    ValueError: distance must be greater than 0

Missing arguments raise a TypeError:

    >>> bg.integer_validator()  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError: missing 2 required positional arguments

    >>> bg.integer_validator("age")  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError: missing 1 required positional argument

area() takes no argument:

    >>> bg.area(1)  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    TypeError: takes 1 positional argument but 2 were given
